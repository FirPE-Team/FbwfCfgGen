# FbwfCfgGen

简体中文 | [English](README.md)

`FbwfCfgGen` 是一个 Rust 命令行工具，用于生成 Windows Embedded 基于文件的写入筛选器（FBWF）使用的二进制 `fbwf.cfg` 配置文件。该工具根据容量值创建一个新的 4096 字节配置文件。

## 用法

```text
FbwfCfgGen <CAPACITY_MB> <OUTPUT_PATH> [--force]
```

示例：

```text
FbwfCfgGen 4096 D:\WinPE\Windows\fbwf.cfg
FbwfCfgGen 8192 D:\WinPE\Windows\custom.cfg --force
```

参数和选项：

- `CAPACITY_MB`：容量，单位为 MB。取值必须在 `128` 到 `131072`（含）之间，并且必须是 16 的倍数。
- `OUTPUT_PATH`：目标文件路径。父目录必须已经存在；文件名不受限制。
- `--force`、`-f`：允许覆盖已存在的目标文件。不会创建 `.bak` 文件。

命令成功时返回 `0`；验证失败或文件写入失败时返回非零值。所有命令行消息均以英文输出。

## 构建

使用 Cargo 构建并运行测试：

```text
cargo build --release
cargo test
```

在 Windows 上，发布版可执行文件会写入 `target/release/FbwfCfgGen.exe`。

## 生成文件格式

每个生成的文件大小都严格为 `0x1000` 字节（4096 字节）。缓冲区首先全部初始化为零，然后写入以下字段：

| 偏移量 |     大小 | 值                               | 用途                      |
| -----: | -------: | -------------------------------- | ------------------------- |
| `0x00` |        1 | `0x24 - byte[0x1C]`，对 256 取模 | 校验字节 A                |
| `0x01` |        2 | `F9 23`                          | 固定签名，小端序 `0x23F9` |
| `0x03` |        1 | `0xF8 - byte[0x1B]`，对 256 取模 | 校验字节 B                |
| `0x04` |        1 | `02`                             | 模板常量                  |
| `0x08` |        1 | `01`                             | 模板常量                  |
| `0x10` |        1 | `02`                             | 模板常量                  |
| `0x1B` |        2 | `CAPACITY_MB / 16`               | 容量单位，小端序 `u16`    |
| `0x20` |        1 | `01`                             | 一个受保护卷              |
| `0x28` |        1 | `02`                             | 模板常量                  |
| `0x2C` | UTF-16LE | 固定卷路径加 NUL                 | 受保护卷路径              |

生成的受保护卷路径为：

```text
\??\Volume{d9b257fc-684e-4dcb-ab79-03cfa2f6b750}
```

该路径以 UTF-16LE 编码，并以一个零值 `WCHAR` 结尾。4096 字节文件中的其余字节保持为零。

## 容量编码

命令接受以 MB 为单位的容量。存储的单位数为：

```text
units = CAPACITY_MB / 16
```

例如，`4096` MB 会以 `0x0100` 的形式存储在偏移量 `0x1B` 和 `0x1C` 处。可接受的最大值 `131072` MB（128 GB）会存储为 `0x2000`。

两个校验字节以交叉顺序使用容量值的高、低字节：

```text
byte[0x00] + byte[0x1C] = 0x24  （8 位回绕）
byte[0x03] + byte[0x1B] = 0xF8  （8 位回绕）
```

## 文件处理和驱动限制

- 只有在容量验证全部通过后，才会写入新文件。
- 除非提供 `--force`，否则已存在的文件会被拒绝。
- 不会自动创建父目录。
- 生成的文件可以复制到 WinPE 映像中，并保存为 `Windows\fbwf.cfg`。
- 实际限制还取决于已安装的 `fbwf.sys`。配置格式最多可表示 128 GB，但 x86 驱动可能会施加更低的运行时限制。

固定卷路径继承自参考配置。如果目标 WinPE 映像保护的是另一个卷，请先获取包含该卷路径的配置，或在使用此文件前更新生成器。
